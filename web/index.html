History

Messages, nicknames and call setup are encrypted in your browser with a key derived from the room ID and PIN. The server only relays ciphertext and never sees the PIN.
    Drop to send. Files are encrypted before upload.

    Keep this chat's history?

    The room becomes Logged. Messages and files from now on, and everything still in memory, are stored encrypted on the server. The self-destruct timer stops. Everyone in the room is notified, and this can't be switched back. The room can still be destroyed at any time.
